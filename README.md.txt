# PHILOCOURS IA

Plateforme numérique d'apprentissage de la Philosophie.

## Fonctionnalités

- Gestion des adhérents
- Paiement MVola
- Validation des tickets
- Carte d'adhérent avec QR Code
- Vérification des adhésions
- Tableau de bord élève
- Tableau de bord administrateur
- Gestion des cours
- Exercices et résultats

## Technologies

- HTML5
- CSS3
- JavaScript
- Supabase
- PostgreSQL
